Daily Progress Logger

Spreadsheet-bound Apps Script. Chat via incoming webhooks. Secrets stay in Script Properties.

Workbook

  • • Team, Chat Spaces, Reminder Matrix, Schedules
  • • One personal tab per member
  • • Weekly Rollup and Weekly Space Summaries
  • • Cells hold property names, not webhook URLs

Clock jobs

  • • Weekdays 18:00 reminder, 19:00 daily post
  • • Monday 09:00 previous-week roll-up
  • • Asia/Kolkata unless both time zone settings change
  • • Space access stays off unless column E should reapply

Boundary

  • • No Google Chat API and no standard Cloud project
  • • Slack path is present and does not send
  • • OpenRouter runs only when a key is stored
  • • clasp push does not upload Script Properties
